# 🚀 Gayathiri Venkatesh - Developer Portfolio

A modern, interactive, and responsive developer portfolio built with **Next.js 15**, **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. The portfolio showcases my projects, technical skills, experience, education, and contact information with smooth animations and a premium user experience.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/gayathirivenkatesh/portfolio.git
```

Go into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
